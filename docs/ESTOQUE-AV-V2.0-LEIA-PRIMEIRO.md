# Sincronização atual do ESTOQUE AV

Use as instruções do arquivo `LEIA-PRIMEIRO-ESTOQUE-V22.md` na raiz do pacote. A sincronização atual usa o mesmo cliente, projeto Supabase e tabela `assistencia_gerencial` do Gerencial, com a linha dedicada `estoque_av_compartilhado_v1`.

Não publique a função `estoque-av-sync` nem execute o SQL da ponte para instalar esta versão. Os arquivos da ponte são mantidos apenas como referência para instalações anteriores.
